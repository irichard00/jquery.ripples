Page Ripple Effect Demo

This page demonstrates a realistic WebGL water ripple effect overlay that distorts the background image beneath it, creating the illusion of viewing content through water.

Controls:

  • Toggle the ripple effect on/off
  • Create ripples at specific coordinates (X, Y pixels from top-left)
  • Trigger an undulating wave effect across the whole page

Note: The effect automatically captures and distorts the page's background image. Mouse cursor interactions are disabled - ripples can only be triggered via coordinate input or the undulate button.
